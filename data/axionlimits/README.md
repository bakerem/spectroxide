# AxionLimits dark-photon limit curves

These files are copied unchanged from [AxionLimits](https://github.com/cajohare/AxionLimits) by C. A. J. O'Hare, commit `7d375f4879b32406a239fe48d2615a4bfd9bc0bb` (2026-01-27), directory `limit_data/DarkPhoton/`. AxionLimits is MIT-licensed; its license is in `LICENSE`.

Paper Fig. 8 (`notebooks/paper_figures/dark_photon_constraints.ipynb`) reads them:

- `COBEFIRAS_Chluba.txt`: the COBE/FIRAS limit of Chluba, Cyr and Johnson (2024), arXiv:2409.12115.
- `COBEFIRAS_Arsenadze.txt`: the COBE/FIRAS limit of Arsenadze et al., arXiv:2409.12940.
- The other eleven files: laboratory limits that make up the gray envelope.

Each file has two columns: dark-photon mass in eV and kinetic mixing ε.
